# Parte I. Primer contacto

En esta primera parte aprenderemos los fundamentos necesarios para comenzar a trabajar con CoppeliaSim. Instalaremos el simulador, conoceremos su interfaz, aprenderemos a movernos por una escena tridimensional y realizaremos las primeras prácticas de manipulación de objetos y programación mediante Python.

El objetivo es que, al finalizar esta parte, seas capaz de desenvolverte con soltura dentro del entorno de simulación y dispongas de una base sólida para comenzar a desarrollar aplicaciones de robótica.

Aunque los ejemplos son sencillos, aquí se introducen muchos de los conceptos que utilizaremos durante todo el libro, por lo que conviene realizar todas las prácticas propuestas antes de continuar con las siguientes partes.

## Capítulos de esta parte

### Capítulo 1. ¿Por qué aprender robótica mediante simulación?

Descubriremos qué es CoppeliaSim, por qué la simulación se ha convertido en una herramienta imprescindible para el aprendizaje de la robótica y cuáles son sus principales ventajas frente al trabajo exclusivo con robots físicos.

### Capítulo 2. Instalación y configuración inicial

Instalaremos CoppeliaSim en Windows, conoceremos las diferentes ediciones disponibles y realizaremos la configuración inicial para comenzar a trabajar con el simulador.

### Capítulo 3. Conociendo la interfaz de CoppeliaSim

Exploraremos todos los elementos de la interfaz de usuario: barra de menús, barra de herramientas, biblioteca de modelos, árbol de la escena, vista tridimensional y consola de mensajes.

### Capítulo 4. Creando nuestra primera simulación

Aprenderemos a crear una escena desde cero, incorporar modelos de la biblioteca, guardar proyectos y ejecutar las primeras simulaciones.

### Capítulo 5. Manipulación de objetos y sistemas de coordenadas

Estudiaremos cómo seleccionar, mover y rotar objetos dentro de una escena, comprendiendo la diferencia entre sistemas de coordenadas globales y locales.

### Capítulo 6. Primera conexión entre Python y CoppeliaSim

Configuraremos un entorno de desarrollo en Python, estableceremos la primera comunicación mediante la API remota ZeroMQ y ejecutaremos nuestros primeros programas para controlar el simulador.
